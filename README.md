
# 🚀 Career Copilot AI

### AI-Powered Resume Optimization Using Agentic AI

**From Learning AI to Building Real-World AI Systems**

Career Copilot AI is an AI-powered resume optimization system that helps job seekers align their resumes with specific job descriptions while preserving authenticity, experience, and original structure.

---

## 🎯 Problem Statement

Many qualified candidates struggle to get shortlisted because their resumes do not effectively reflect the skills and keywords required in job descriptions.

### Key Challenges
- Missing job-specific keywords
- Poor alignment with job requirements
- Generic resumes for different job applications
- Difficulty optimizing resumes manually
- Time-consuming resume customization

---

## 💡 Our Solution

**Career Copilot AI** uses Large Language Models (LLMs), prompt engineering, and agentic AI workflows to optimize resume content based on specific job requirements.

### ✨ Key Features

- 📄 **Resume Analysis** — Analyzes existing resume content
- 🎯 **Job Description Matching** — Identifies role-specific requirements
- 🔑 **Keyword Optimization** — Incorporates relevant keywords naturally
- 🤖 **AI-Powered Suggestions** — Improves the wording of existing experience
- 🛡️ **Authenticity Preservation** — Avoids fabricated qualifications
- 📝 **Structure Preservation** — Maintains the original resume organization
- ⚡ **FastAPI Integration** — Supports backend API processing

## ⚙️ How It Works

### Step 1: Upload Resume
The user provides their existing resume.

### Step 2: Provide Job Description
The user enters the job description of the target role.

### Step 3: AI Analysis
The LLM identifies relevant skills, requirements, and keywords.

### Step 4: Resume Optimization
The system improves wording and aligns existing experience with job requirements.

### Step 5: Generate Optimized Resume
The user receives optimized resume content tailored to the job description.

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/career-copilot-ai.git
cd career-copilot-ai
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Virtual Environment

**Windows:**
```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
```

### 6. Run the Application

If your FastAPI app is defined in `main.py`:

```bash
uvicorn main:app --reload
```

### 7. Open API Documentation

```text
http://127.0.0.1:8000/docs
```
